**English** · Download **`ChestCounter.exe`** below, run it, follow the short setup. Nothing to install. Already using it? Press **U** in the counter: your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory. Its only network access is the check for a new version on GitHub (can be turned off).

**What's new in 1.4.0**
- **New default overlay**, nicer and transparent. The old one is still there: *Settings → Overlay style → classic*
- **Chest count fixed**: it was wrong in some cases. The replays still on your PC are analyzed again and your counters adjusted
- **New console**, simpler and more intuitive to use
- **New report design**
- **Team treasures**: can be shown or hidden in the report (an estimate, sometimes wrong)
- **The overlay can be turned off** entirely in the settings
- Thanks to koiseka for their contribution (#6)

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.

**Русский** · Скачай **`ChestCounter.exe`** ниже, запусти и пройди короткую настройку. Устанавливать ничего не нужно. Уже пользуешься? Нажми **U** в счётчике: история и настройки сохранятся.

> **Сначала включи запись повторов в Fortnite**: *Настройки → Игра → Повторы → Записывать повторы: Вкл.* Программа только читает файлы повторов: никаких изменений игры, никакого доступа к памяти игры. Единственное обращение к сети — проверка новой версии на GitHub (можно отключить).

**Что нового в 1.4.0**
- **Новый оверлей по умолчанию**, красивее и прозрачный. Прежний остался: *Настройки → Стиль оверлея → классический*
- **Исправлен подсчёт сундуков**: в некоторых случаях он был неверным. Повторы, оставшиеся на ПК, анализируются заново, счётчики пересчитываются
- **Новая консоль**, проще и понятнее
- **Новый дизайн отчёта**
- **Сокровища команды**: можно показать или скрыть в отчёте (оценка, иногда неточная)
- **Оверлей можно полностью отключить** в настройках
- Спасибо koiseka за вклад (#6)

Windows может показать *«Система Windows защитила ваш компьютер»* (exe без подписи): *Подробнее → Выполнить в любом случае*.
