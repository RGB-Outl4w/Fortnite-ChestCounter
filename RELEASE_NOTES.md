**English** · Download **`ChestCounter.exe`** below and run it. Nothing to install. Already using it? Click **Install** on the home tab: your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory. It only goes online to GitHub: the check for a new version (can be turned off), the treasure hunt data and, once, the treasure pictures.

**What's new in 1.6.1**
- Brings the original project's 1.5.1, in English and Russian:
- **Clearer chances**: a chest only gives the treasure of its week, so the weekly treasures (gold outfit, vehicle & decal, pickaxe or back bling, jam track, loading screen) now count this week's chests only: their chance is lower than in 1.6.0, and right. A word for each chance (*Likely*, *Almost certain*…), never "100%", this week's items with their picture, and countdowns until they leave and until the next Treasure Hour
- **Times**: in Settings, times in local time or UTC, with a 12- or 24-hour clock
- **Overlay**: the last match stays shown during the next one, and a red dot next to the total says a match is in progress
- **Chests added by hand** (the pencil of *Chests in total*): each number is now added to the previous ones, a list shows every addition with a cross to undo it, and *Opened this week* makes them count in this week's chances. A new estimate from the Career tab replaces the previous one
- **Fixes**: closed chests you break without touching them are counted again (the replays still on your PC are analyzed again). The Activity log no longer jumps back to the top. A quick click on a tab is no longer lost, and the edit box no longer closes when you release the mouse outside it

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*. The window needs Microsoft Edge WebView2 (built into Windows 11); without it, the same page opens in your browser.

**Русский** · Скачай **`ChestCounter.exe`** ниже и запусти. Устанавливать ничего не нужно. Уже пользуешься? Нажми **Установить** на главной вкладке: история и настройки сохранятся.

> **Сначала включи запись повторов в Fortnite**: *Настройки → Игра → Повторы → Записывать повторы: Вкл.* Программа только читает файлы повторов: никаких изменений игры, никакого доступа к памяти игры. Она обращается только к GitHub: проверка новой версии (можно отключить), данные охоты за сокровищами и, один раз, изображения сокровищ.

**Что нового в 1.6.1**
- Версия 1.5.1 исходного проекта, на английском и русском:
- **Понятнее шансы**: сундук даёт только сокровище своей недели, поэтому еженедельные сокровища (золотой наряд, транспорт и наклейка, кирка или украшение на спину, джем-трек, загрузочный экран) теперь учитывают только сундуки этой недели: их шанс ниже, чем в 1.6.0, и это правильно. Словесная оценка каждого шанса (*Вероятно*, *Почти наверняка*…), никогда не «100%», предметы этой недели с картинкой, обратный отсчёт до их ухода и до следующего Часа сокровищ
- **Время**: в настройках — местное время или UTC, 12- или 24-часовой формат
- **Оверлей**: последний матч остаётся на экране во время следующего, а красная точка рядом с итогом показывает, что идёт матч
- **Сундуки, добавленные вручную** (карандаш у *Всего сундуков*): каждое число теперь прибавляется к прежним, список показывает все добавления с крестиком для отмены, а *Открыты на этой неделе* учитывает их в шансах этой недели. Новая оценка по «Карьере» заменяет прежнюю
- **Исправления**: закрытые сундуки, сломанные без открытия, снова считаются (повторы, оставшиеся на ПК, анализируются заново). Журнал на главной больше не прыгает вверх. Быстрый клик по вкладке больше не теряется, а окно правки не закрывается, если отпустить мышь за его пределами

Windows может показать *«Система Windows защитила ваш компьютер»* (exe без подписи): *Подробнее → Выполнить в любом случае*. Окну нужен Microsoft Edge WebView2 (встроен в Windows 11); без него та же страница открывается в браузере.
